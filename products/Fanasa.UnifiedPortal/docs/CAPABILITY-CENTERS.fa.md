# مراکز قابلیت پنجره واحد فن‌آسا

پنجره واحد با یک taxonomy مستقل، مسیر دسترسی به قابلیت‌های فن‌آسا را دسته‌بندی
می‌کند. این دسته‌بندی در این مرحله قراردادی برای ناوبری و کشف محصول است؛ منطق
دامنه‌ی محصولات داخل پنجره واحد کپی نمی‌شود.

| شماره | مرکز قابلیت | محصول/وضعیت فعلی |
|---:|---|---|
| ۰۱ | مدیریت کار و پروژه | مدیریت کار ایجنتیک |
| ۰۲ | ارکستراسیون ایجنت‌ها | مدیریت کار ایجنتیک |
| ۰۳ | توسعه و DevOps | مدیریت کار ایجنتیک |
| ۰۴ | قرارداد و امور حقوقی | مدیریت قرارداد |
| ۰۵ | مشتری و ارتباطات | در حال طراحی |
| ۰۶ | فروش و رشد | در حال طراحی |
| ۰۷ | مالی و حسابداری | در حال طراحی |
| ۰۸ | منابع انسانی | در حال طراحی |
| ۰۹ | عملیات و فرآیند | در حال طراحی |
| ۱۰ | اسناد و دانش | در حال طراحی |
| ۱۱ | همکاری و ارتباطات | در حال طراحی |
| ۱۲ | داده و هوش مصنوعی | در حال طراحی |
| ۱۳ | هویت و امنیت | Keycloak مرکزی فن‌آسا |
| ۱۴ | یکپارچه‌سازی و API | در حال طراحی |

برای هر مرکز، وضعیت فعال یا به‌زودی از روی URL محصول و تنظیمات deployment مشخص
می‌شود. نام‌ها باید با فهرست رسمی مرکز قابلیت فن‌آسا قابل جایگزینی بمانند؛ برای
این منظور UI فعلاً داده را در یک catalog متمرکز نگه می‌دارد و به سرویس دامنه‌ای
وابسته نیست.
