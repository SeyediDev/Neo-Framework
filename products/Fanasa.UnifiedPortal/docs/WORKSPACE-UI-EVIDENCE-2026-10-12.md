## مرز پذیرش

دادهٔ درخواست، مصرف، عرضه و بررسی ادمین مصنوعی است و provider آن فقط در اسمبلی
آزمون قرار دارد. تأیید درخواست، grant یا قرارداد واقعی ایجاد نمی‌کند. کارت سرویس
شبیه‌سازی‌شده URL ورود ندارد. تأیید پیشنهاد عرضه، محصول یا تعرفه‌ای نمی‌سازد.
اجرای واقعی همچنان از provider صریح `NotConnectedWorkspaceJourneySource` استفاده
می‌کند؛ فهرست سرویس‌های مجاز از خوانندهٔ مرکزی موجود می‌آید.

حالت `connected` در مرورگر با تغییر bootstrap روی همان میزبان مصنوعی بررسی شد:
سابقهٔ نمونه خوانده نشد، فرم‌ها غیرفعال و مقادیر نامعلوم با خط تیره نمایش داده
شدند و فقط لینک‌های مجاز bootstrap قابل ورود بودند. این شبیه‌سازی، احراز هویت
یا حسابداری واقعی production را اثبات نمی‌کند. آزمون مدل، حفاظت صفحه، subject
نشست، سازمان تأییدشده، envelope مصرف‌کننده، عدم نمایش لینک قبلی و escaping JSON
را جداگانه پوشش داد.

این تغییر انتشار خارجی، ثبت محصول، تغییر SSO، grant، حسابداری یا زیرساخت جدید
انجام نداده است. Skill و schema ابزار MCP موجود از این seam نمایشی استفاده
نمی‌کنند؛ مستندات محصول و قرارداد UI به‌روزرسانی شدند و بازنویسی MCP لازم نبود.
